# Запас — помощник продавца Ozon / Wildberries

## Загрузить на GitHub и запустить хостинг

Подробная пошаговая инструкция: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

Код готов к размещению на Linux-сервере через Docker Compose: приложение + HTTPS через Caddy.
Это серверное приложение с Telegram-ботом и базой данных. GitHub Pages его не запускает.
Проект пока требует пилотного тестирования на настоящих магазинах; подготовка хостинга не означает проверку всех интеграций.

| Папка / файл | Назначение |
| --- | --- |
| `static/` | Интерфейс сайта, стили, шрифты и логотип |
| `*.py` в корне | Сервер, интеграции, бот и расчёты |
| `deploy/` | Настройка HTTPS |
| `scripts/` | Настройка бота, резервные копии, упаковка исходников |
| `tests/` | Автоматические проверки |
| `.env.example` | Образец настроек без секретов |
| `compose.yaml`, `Dockerfile` | Запуск на сервере |

Никогда не загружайте `.env`, базы данных, `zapas_accounts/`, `runtime/` или резервные копии.
Для локального запуска: `python -m pip install -r requirements.txt`, затем `python app.py`.
Открыть: http://127.0.0.1:8765 (локальная панель владельца). Не публикуйте этот порт.

## Примечания к локальной версии


Первая локальная версия помощника продавца: остатки → оценка запаса → уведомление в Telegram.
Python 3.11+; зависимости перечислены в requirements.txt.

## Посмотреть

```powershell
python app.py
```

Откройте http://127.0.0.1:8765. Без ключей работает **демо** с вымышленными Ozon/WB товарами.
Автоуведомления демо не отправляются. Поиск, фильтры и сохранение правил работают.

## Студия и мобильная версия

Раздел **Студия** содержит три инструмента:

- **Подключения**: ввод токенов через локальную форму, без редактирования файлов.
  Telegram-токен проверяется методом getMe, существующий webhook не удаляется.
  Ozon/WB считаются только добавленными до успешной синхронизации.
  Ключи шифруются Windows DPAPI и хранятся в SQLite: расшифровать их может тот же пользователь Windows.
  Они не возвращаются в API интерфейса и не попадают в экспорт. Для другого сервера использовать
  переменные окружения/подходящее хранилище секретов; перенос шифрованной БД сам по себе не переносит ключи.
- **Конструктор сайта**: тексты, три цветовые темы, блоки преимуществ и шагов, ссылка CTA.
  Предпросмотр реагирует на ввод; сохранение в SQLite отдельно. Экспорт ZIP содержит статическую
  страницу, CSS, локальный шрифт и лицензию, без БД или секретов. Экспорт не означает публикацию.
  Пока ссылка CTA не введена, форма записи не имитируется. Это конструктор страницы продукта,
  а не универсальный редактор произвольных многостраничных сайтов.
- **Конструктор бота**: приветствие, три кнопки меню, фильтры предупреждений и симулятор,
  использующий ту же серверную функцию ответов, что и Telegram. Симулятор ничего не отправляет.
  Настоящие ответы включаются отдельно; нужен токен и разрешённый chat ID. Внешним чатам данные
  не возвращаются. Название в редакторе — название предпросмотра, не переименование профиля BotFather.

В демо **автоматические предупреждения** не отправляются. Если подключить настоящий бот и включить
его ответы, он может по запросу разрешённого чата показать явно помеченную демо-сводку.

На телефоне — нижняя навигация, формы в одну колонку, кнопки от 44px, поля 16px без автозума iOS.
Проверена ширина 390px. Локальный адрес 127.0.0.1 доступен на этом компьютере: мобильная адаптация
не означает, что сайт уже размещён для доступа с физического телефона через интернет.

Для удобного повторного запуска: `Start-Zapas.ps1` запускает приложение скрыто и открывает браузер.
Он не добавляет автозапуск Windows, не меняет политику выполнения скриптов и не открывает сетевые порты.
Для работы 24/7 всё ещё требуется сервер с авторизацией и HTTPS.

## Настоящие Ozon / WB

Задайте переменные окружения в локальном терминале, затем запустите `python app.py`:

- `OZON_CLIENT_ID` — идентификатор продавца.
- `OZON_API_KEY` — ключ с минимально необходимыми правами чтения остатков и аналитики.
- `WB_API_TOKEN` — допустимый для вашей локальной интеграции токен с доступом к аналитике,
  статистике заказов и тарифам. Для облачного коммерческого сервиса персональный токен не использовать.
- `TELEGRAM_BOT_TOKEN` — токен вашего бота из BotFather.
- `TELEGRAM_CHAT_ID` — ваш чат; сначала откройте бота и нажмите Start.

Не отправляйте ключи в чат и не добавляйте их в Git. Интерфейс не принимает и не возвращает ключи.
Без двух переменных Telegram сигналы остаются в очереди. Перед включением живой доставки
просмотрите очередь: она может содержать ещё актуальные предупреждения прошлых запусков.

Сервис автоматически проверяет магазин каждые 15 минут, пока запущен процесс и компьютер работает.
Данные хранятся локально в `zapas.sqlite3`. Для круглосуточной работы понадобится сервер.
Запросы выполняются только на официальные HTTPS-адреса Ozon, WB и Telegram.

## Что реализовано

- Ozon `/v4/product/info/stocks` с пагинацией; поддержаны массив и объект `stocks`.
- Остатки отдельно по схемам FBO/FBS: `max(0, present - reserved)`. Семантику и соответствие
  кабинету необходимо сверить на живом магазине перед коммерческим использованием.
- История SKU/день за 56 полных UTC-дней из `/v1/analytics/data`, база спроса — последние 14 дней.
- WB: `/api/analytics/v1/stocks-report/wb-warehouses`, агрегирование размеров по nmId;
  `/api/v1/supplier/orders` с исключением отменённых заказов. Ozon ordered_units и WB неотменённые
  заказы не идентичны по смыслу: при живой сверке учитывать различие.
- Всплеск последних 3 дней не заменяет основу 14 дней: он формирует отдельный осторожный сценарий.
- При полной истории 56 дней вычисляется недельный рисунок спроса; годовая сезонность не рассчитана.
  Акцию/сезон можно задать множителем вручную. Нет обещаний точной модели сезонности.
- Срок до продажи = подготовка + доставка + приёмка (минимум/максимум), плюс страховой запас
  при расчёте безопасной даты заказа. Значения сохраняются отдельно для каждого товара.
- «Цена ожидания»: сравнение отправки сейчас и после заданной задержки для одинаковой партии
  и общего горизонта. Модель оценивает приёмку и недополученный маржинальный доход.
  Это не чистый убыток, не вероятность и не гарантия оптимального действия. Диапазон получен
  перебором сроков/темпов, это не статистический доверительный интервал.
  Общий горизонт заканчивается после наиболее позднего появления обеих сравниваемых партий
  в продаже. Это краткосрочная оценка задержки, не модель всей будущей прибыли магазина.
- Расчёт приёмки всей партии = введённая базовая стоимость × коэффициент. Доставка, хранение,
  уже едущие партии, региональная доступность, возможная бронь слота и штрафы в сравнении не учтены.
- Адаптер тарифов WB `/api/tariffs/v1/acceptance/coefficients`: метод может быть временно отключён.
  Ошибки видны, старый тариф не подставляется как свежий. Только подходящий тариф не старше часа
  для выбранных склада/упаковки/даты прибытия с allowUnload и коэффициентом 0/1 может подменить
  ручное значение. Будущий коэффициент ожидания всегда остаётся допущением продавца.
  Изменение тарифа выбранного склада/даты/упаковки сохраняет уведомление в очередь.
- Артикулы вместо названий в живом режиме: запрос карточек ещё не реализован.
- Порог количества и дней; отсутствие аналитики показывается как отсутствие данных.
- Сигнал при изменении уровня риска; после восстановления остатка сигнал снова разрешён.
- Очередь отправок: доставка считается успешной только после подтверждения Telegram.
  После 5 ошибок отправка приостанавливается; автоматического сброса попыток в этой версии нет.
  При потере ответа после принятия сообщения Telegram повтор возможен (доставка at-least-once).
- Сохраняются последние данные при ошибках; на экране появляется предупреждение.
- Пороговые правила применяются к отправкам при очередной синхронизации.

## Границы первой версии

**Это не запущенный платный сервис.** Живые API и отправка в Telegram без ключей не проверены.
Адаптеры WB/Ozon написаны и проверяются на подменённых ответах, не на настоящих аккаунтах.
Старый `/api/v1/supplier/stocks` не используется. Тарифы WB без токена не проверены.
Нет регистрации покупателей, оплаты, изоляции нескольких продавцов, ежедневных сводок,
заказов/возвратов, автоматического развёртывания и круглосуточного мониторинга процесса.

Сервер слушает только localhost, проверяет Host и CSRF-токен. Не открывайте его в интернет
через проброс порта: для публичной версии нужны HTTPS, авторизация, шифрование ключей,
изоляция магазинов и резервное копирование. Все локальные пользователи компьютера с доступом
к файлам/процессу должны считаться доверенными.

### Выбор маркетплейса и логотип

При открытии показывается выбор Ozon / Wildberries. Кнопка в шапке позволяет переключить площадку. Выбор сохраняется для текущей однопользовательской панели: сервер фильтрует товары, события, ответы бота и очередь отправки; интерфейс показывает соответствующее подключение и поля планировщика. Профили товаров сохраняются при переключении. Это не система отдельных аккаунтов покупателей. SVG-логотип находится в `static/logo.svg`, используется в шапке, приветствии и favicon.

Пробный срок — 7 дней после первой успешной загрузки настоящего непустого магазина. Описание функций, ограничения и настройка оплаты — в `ТАБЛИЦА_И_ПОДПИСКА.md`.
