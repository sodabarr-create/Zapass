Ozon

Нужны Client ID и API-ключ с правами чтения остатков и аналитики.

Где взять Client ID и ключ Ozon?
  1. Войдите в свой кабинет Ozon Seller и выберите нужную компанию.
  2. Откройте настройки, найдите раздел «API-ключи» / Seller API.
  3. Скопируйте Client ID. Создайте отдельный ключ для этой интеграции с правами чтения нужных данных: товары, остатки и аналитика.
  4. Вставьте Client ID и ключ в поля ниже и сохраните. Затем нажмите «Обновить данные» в шапке.
  5. Проверьте время обновления и сообщения об ошибках. Сохранение ключа ещё не подтверждает загрузку магазина.
Официальная инструкция Ozon ↗

Не передавайте пароль от кабинета или API-ключ в чат. Названия пунктов в кабинете могут меняться.

Wildberries

Нужен разрешённый для вашей интеграции токен: аналитика, статистика и тарифы. Доступ к тарифам может быть ограничен.

Где взять токен Wildberries?
  1. Владелец магазина открывает профиль WB Partners → «Интеграции по API» → «Создать токен».
  2. Для ручной тестовой интеграции изучите условия базового токена. Сервисный токен привязан к сервису из каталога; персональный нельзя передавать стороннему облачному сервису.
  3. Выберите нужные категории данных: отчёты остатков и заказов, цены и скидки, контент для карточек и габаритов. Используйте чтение без изменения товаров, где это доступно.
  4. Скопируйте токен при создании, вставьте ниже и сохраните. Нажмите «Обновить данные».
  5. Проверьте ошибки и время обновления: доступность отчётов и лимиты зависят от типа токена.
Официальная инструкция Wildberries ↗

Ключи не нужно присылать в переписку. Для коммерческой облачной версии нужно отдельно проверить разрешённый площадкой способ интеграции.

Сейчас список строится по отчётам остатков. Карточки, которых нет в ответах этих отчётов, могут не появиться. Полнота каталога и реальные данные ещё требуют проверки. Для проверки магазинов после сохранения нажмите «Обновить данные». Telegram-ответы включаются отдельно в конструкторе бота. Для работы 24/7 приложение должно быть запущено на сервере.

ПОНЯТНО С ПЕРВОГО РАЗА

Как пользоваться «Запасом»

От первого открытия до первых полезных предупреждений.

1. Откройте приложение

В чате нажмите «Открыть Запас» рядом с полем сообщения или отправьте /app и нажмите кнопку «Открыть приложение». Выберите Ozon или Wildberries. Поменять площадку можно кнопкой в шапке.

2. Разберитесь на демо

Надпись «ДЕМО» означает, что товары вымышленные. Можно изучить вкладки и расчёты без подключения магазина. Демо не отправляет автоматические предупреждения.

3. Подключите свой магазин

Откройте «Студия → Подключения». Для Ozon нужны Client ID и API-ключ; для WB — API-токен с доступом к используемым отчётам. Вводите ключи только в форме, не в чате. По возможности используйте права только на чтение. Нажмите «Сохранить», затем «Обновить данные». Проверьте отсутствие ошибок и время обновления: сохранённый ключ ещё не означает успешную загрузку.

4. Настройте сроки пополнения

В обзоре выберите товар, откройте «Настроить поставку, спрос и стоимость». Укажите подготовку партии, доставку, минимум и максимум приёмки и страховой запас. Считайте до момента, когда товар снова можно купить. Пример: 2 дня подготовки + 3 дороги + 2–5 приёмки = 7–10 дней до продажи. Нажмите «Сохранить и пересчитать».

5. Читайте подсказку

«Пора оформлять поставку» означает, что безопасная дата пополнения уже наступила с учётом ваших сроков. Основа спроса — 14 полных дней; последние 3 дня показывают возможный всплеск. Для ожидаемой акции или сезона задайте множитель: 1 — без изменения, 1,5 — рост на 50%. Это ваша оценка, не автоматическое знание будущего.

6. Сравните варианты

Раскройте «Сравнить стоимость». Для оценки в рублях заполните доход с продажи после расходов, стоимость приёмки партии и коэффициенты. Не знаете стоимость — оставьте коэффициент пустым. Для WB данные тарифа используются только при подходящем свежем ответе API, иначе расчёт опирается на ваши допущения. Будущий коэффициент не гарантирован. Сравнение не бронирует склад и не закупает товар.

7. Включите нужные сигналы

В «Настройках» задайте пороги количества и дней. В «Студия → Конструктор бота» выберите предупреждения и сохраните сценарий. Очередь и статус доставки видны в «Событиях». Повторные сигналы появляются при изменении уровня риска, а не при каждой проверке. Проверка по расписанию — раз в 15 минут, пока сервер работает.

8. Если что-то не открывается

Закройте Mini App и откройте заново постоянной кнопкой рядом с полем сообщения. Старые кнопки в сообщениях могут вести на истёкший тестовый адрес. При ошибке API проверьте права и срок действия ключа. Если данные не обновились — смотрите время последнего обновления, а не принимайте старый остаток за новый.

9. Проверьте доход с товара

Откройте «Прибыль» или кнопку дохода в таблице товаров. Цены и габариты загружаются отдельными запросами API при наличии доступа. Укажите себестоимость, комиссию, налог и расходы на единицу. Если расхода нет — введите 0; неизвестное оставьте пустым. Вы увидите оценку дохода и цену, которая покрывает расходы. При разных ценах размеров расчёт не выбирает дешёвый размер молча: укажите нужную цену сами.

Что важно знать о пилоте

Mini App владельца остаётся личным. Для самостоятельной веб-версии добавлены отдельные кабинеты по логину и паролю; уведомления привязываются к Telegram одноразовой ссылкой из своего кабинета. СБП предназначена для самостоятельного сайта. Приём денег пока отключён: цена и платёжный аккаунт не настроены. Ключи магазинов ещё нужно проверить на реальных данных. Прогноз не учитывает автоматически все партии в пути, возвраты и отмены; отдельные уведомления о каждом новом заказе и возврате ещё не реализованы. Для постоянной работы нужны сервер и стабильный HTTPS-адрес.
